# 亮哥发版助理 · 朋友首装入口

这是 liangge 的 public 入口仓库, 仅放朋友首装时需要拉取的脚本和 release-updater 客户端代码.

## 朋友首装

curl -fsSL https://cdn.jsdelivr.net/gh/zhaoliang1926-tech/liangge-public@main/install.sh | bash -s -- --onb-token onb_xxxxx

onb_xxxxx 由亮哥通过飞书私聊发给你, 仅你能用.

## 卸载

curl -fsSL https://cdn.jsdelivr.net/gh/zhaoliang1926-tech/liangge-public@main/uninstall.sh | bash
